One X post promoting make.fun's make-your-own-bounty post — the post itself is the entry. It quotes make.fun's post (https://x.com/makefunai/status/2124915864336236646), carries its own photo, make.fun in its text and the entrant's play code. Places go by the post's replies + reposts + quotes. This repo only hands the post's address (POST.json) to the gate; the program validates the address is a real X post URL and refuses a placeholder.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
